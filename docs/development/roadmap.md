# Roadmap de desenvolvimento

| Fase | Escopo |
| --- | --- |
| Phase 0 — Architecture | Fundação documental e estrutural. |
| Phase 1 — Tool Registry | Catálogo e contratos de ferramentas. |
| Phase 2 — Dataset Registry | Identidade, metadados e linhagem de datasets. |
| Phase 3 — Provenance | Registro auditável de execuções e decisões. |
| Phase 4 — QC Workflow | Primeiro workflow de controle de qualidade. |
| Phase 5 — Execution Layer | Contratos e implementações graduais de executores. |
| Phase 6 — Workflow Engine | Dependências, estados e reexecuções. |
| Phase 7 — Agentic Harness | Controles para assistência orientada a agentes. |
| Phase 8 — Specialized Agents | Papéis científicos especializados. |
| Phase 9 — Scientific Validator | Validações técnicas e científicas. |
| Phase 10 — Orchestrator | Coordenação de pedidos, políticas e workflows. |
| Phase 11 — Data Science/ML | Capacidades de dados e aprendizado de máquina. |
| Phase 12 — FastAPI | Interface programática. |
| Phase 13 — Frontend | Interface de usuário. |
| Phase 14 — Cloud execution | Execução gerenciada em nuvem. |
| Phase 15 — Local migration | Migração e suporte a execução local. |

O avanço entre fases dependerá de revisão de escopo, capacidade de infraestrutura e validação dos artefatos da fase anterior.
